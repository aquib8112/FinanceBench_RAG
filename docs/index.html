About the project

A financial-document retrieval-augmented generation (RAG) project built by Aquib Ahmad. It searches 84 financial documents (~12,000 pages, 10M+ tokens): 10-Ks, 10-Qs, 8-Ks, and earnings releases.

Questions are decomposed into focused searches. BM25 and semantic search retrieve pages by searching their summaries. An evidence judge assesses the original pages for their usefulness in answering the question. Answers are then generated from the selected original pages, with citations. LangSmith traces the pipeline.

The system achieved 87.3% answer accuracy (131/150) on the 150 public FinanceBench questions.

The demo searches only the available filings. Answers can be incomplete or incorrect; check the cited sources.
